# ROP — Limitations and Disclaimers

This document must be read before using or demonstrating this prototype.

---

## Data Status

All regulatory data in this prototype is **DEMO** status unless explicitly
marked **VERIFIED** with:
- `source_url`: URL of official government source
- `source_title`: Name of Act, Rule, or notification
- `source_date`: Date of the official document
- `reviewed_by`: Name of person who verified

## What This Prototype Does NOT Do

- This prototype does **not** replace official government portals
  (MAITRI, NSWS, or any state portal).
- This prototype does **not** submit actual applications to government.
  All submissions are sandbox/mock only.
- This prototype does **not** provide legal advice.
- This prototype does **not** guarantee regulatory compliance.
- AI-assisted features are assistance only. AI output must be
  confirmed by the user. AI does not determine regulatory truth.

## Government Integrations

All government API integrations are mock (MockAdapter).
No real API endpoints are called.
Actual processing remains with the respective government authorities.

## Demo Statistics

Any statistics, processing times, or counts shown are illustrative
and do not represent real government data.

## SLA Values

All SLA values in the prototype are DEMO/CONFIGURATION_REQUIRED
unless sourced from official government notifications.

## Prototype Scope

This is an academic prototype built for SIH 2026 competition purposes.
It demonstrates an orchestration concept, not a production system.
